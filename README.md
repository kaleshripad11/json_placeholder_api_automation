# JSONPlaceholder REST API Test Automation
<h5>🚀 Overview</h5>
<p>This project provides a modular and reusable test automation framework for validating REST APIs.
<p>It uses:
<ul>
    <li>Python requests for API calls</li>
    <li>Pytest for test execution and reporting</li>
    <li>Custom API client (Api_Client_Base) for consistent request handling</li>
    <li>Config-driven setup for base URLs, headers, and payloads</li>
    <li>YAML/JSON data files for test input management</li>
</ul>
